# Sales Performance Dashboard

## Project Overview
This Power BI dashboard analyzes sales performance across regions, products, and months.

## KPIs
- Total Revenue
- Total Orders
- Total Products Sold

## Dashboard Features
- Revenue by Region
- Monthly Sales Trend
- Product-wise Sales Analysis
- Region Filter
